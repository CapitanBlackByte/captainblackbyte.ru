Возможности

Всё, чем живёт команда

Задачи, продажи и заказчики в одной системе. Каждый экран обновляется в реальном времени, поэтому никто не работает со старыми данными.

Обзор

День начинается с главного

На первом экране просроченные и сегодняшние задачи, ближайшие на неделю, выручка месяца против плана и сделки без следующего шага.

  • «Мой день»: выполнение отмечается прямо из списка
  • Взвешенный прогноз по сделкам и воронка по этапам
  • Загрузка команды для руководителя: открытые, просроченные и закрытые задачи по сотрудникам
  • Лента последних действий

Задачи

Доска, список и календарь

Три вида одних и тех же задач, переключение клавишами 1, 2 и 3. Карточки перетаскиваются между колонками, у колонок есть лимиты задач в работе.

  • Проект, этап, задача и подзадача, чек-листы и теги
  • Оценка и списание времени, сроки с быстрыми пресетами
  • Комментарии с упоминаниями @сотрудника и журнал изменений
  • Фильтры сохраняются в ссылке, ею можно поделиться
  • Ctrl K: поиск по задачам, сделкам, заказчикам и контактам

Сделки и заказчики

Воронки продаж

Канбан по этапам с перетаскиванием и несколько воронок. В карточке сделки сумма, вероятность, дата закрытия, источник, контакт, связанные задачи и история.

  • Фильтры «без следующего шага» и «с просроченными задачами»
  • Компании и физлица с ИНН, сайтом и ответственным
  • Страница заказчика: сделки, контакты, задачи и выигранные суммы
  • Выгрузка заказчиков в CSV, который открывается в Excel

Аналитика

Продажи и скорость команды

Выручка, выигранные сделки, средний чек, конверсия воронки и динамика по дням, неделям или месяцам, с разрезом по менеджерам и источникам.

  • По задачам: время цикла и доля выполненных в срок
  • Создано и закрыто по периодам, нагрузка по сотрудникам
  • Периоды 7, 30, 90 и 365 дней

Боты и API

Боты, как в Telegram

Встроенный «Помощник Flow» показывает задачи и сделки, создаёт задачу командой /new и отмечает выполненное кнопкой. Свои боты создаются в переписке с BotFather.

  • Bot API по образцу Telegram: подходят grammY, Telegraf и python-telegram-bot
  • Команды через /, кнопки под сообщениями и своя клавиатура бота
  • Вебхуки и подписка на события CRM: задачи, сделки, заказчики
  • С тем же токеном бот работает с задачами и сделками через API

  • Роли и права

    Администратор, руководитель отдела и менеджер. Видимость: свои данные, отдел или всё.

  • Уведомления

    Назначение задачи, упоминание, выполнение, напоминания о сроке и просрочке.

  • Контроль доступа

    Новые сотрудники ждут подтверждения администратора. Есть журнал действий и список активных сессий.

  • Горячие клавиши

    C создаёт задачу, G с буквой переходит по разделам, ? показывает все сочетания.

  • На телефоне

    Вёрстка подстраивается под экран, внизу навигация по разделам. Есть тёмная и светлая тема.

  • Запас по нагрузке

    Один сервер API рассчитан на 1 500–2 000 активных сотрудников. Под нагрузку добавляются новые.

Вопросы

Прежде чем подключить

Чем Flow отличается от Битрикс24?

Flow сделан для команд, которые ведут проекты заказчиков: в нём задачи, сделки, заказчики, аналитика и боты. В Битрикс24 больше модулей, например диск, сайты и контакт-центр. Если они Вам не нужны, во Flow за них не придётся платить.

Сколько сотрудников выдержит?

В нагрузочном тесте «Рабочий день» Flow обслужил 3 000 сотрудников онлайн одновременно без единой ошибки. Половина экранов открывалась быстрее чем за 13 мс, 99% быстрее чем за 0,15 с. Один сервер API рассчитан на 1 500–2 000 активных сотрудников, для большего числа добавляются новые.

Можно подключить свои сервисы?

Да. Bot API во Flow сделан по образцу Telegram, поэтому подходят готовые библиотеки grammY, Telegraf и python-telegram-bot: достаточно указать адрес CRM вместо api.telegram.org. С тем же токеном бот работает с задачами, сделками и заказчиками и получает события об их изменениях.
